# Lingua — TRANSLATE-AI

Адаптивный интерфейс переводчика с режимами текста, голосового ввода и загрузки изображений.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Голосовой ввод использует Web Speech API браузера (Chrome/Edge, при разрешении микрофона), озвучивание — Speech Synthesis. Для реального перевода и OCR необходимы подключения к соответствующим сервисам; в автономной демо-версии переводятся распространённые короткие фразы, а остальные случаи явно помечаются.

## Android APK

Нативная оболочка WebView находится в `android/`. GitHub Actions собирает debug APK при каждом push и вручную через вкладку **Actions → Build Android APK → Run workflow**. Готовый `app-debug.apk` доступен как артефакт запуска workflow (скачать можно со страницы завершённого запуска; срок хранения — 30 дней).
